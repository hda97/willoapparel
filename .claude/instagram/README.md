# Data akun Instagram untuk skill ig-*

- `ATURAN.md`: aturan bersama yang wajib diikuti semua skill.
- `duniakotak.id/`: akun game Dunia Kotak (antrean posting `konten-ig/antrean/`).
- `miftakhul_hda/`: akun pribadi Huda untuk aplikasi Lumbung (antrean `konten-ig/antrean-miftakhul_hda/`).

Tiap folder akun berisi `voice.md` (suara akun, diisi). Skill akan menulis `swipe.md` (ig-viral),
`plan.md` (ig-plan), dan `log.md` (ig-reel/ig-comment) di folder yang sama.
`_template-voice-asli.md` = templat asli dari paket, untuk akun baru.
