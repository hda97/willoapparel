# Touchpoints

Illustrations exist to do jobs in specific places. Map those places before choosing a style. Mature systems assign
illustration types and density by surface because not every image serves the same purpose.

## 1. Inventory the surfaces

Look at the brand's actual product and channels (app screens, website, social, emails, store listings, print). If
there is a codebase or design system in the workspace, read its empty-state, error, onboarding and success components.
List every place an illustration does or could appear.

| Tier | Typical touchpoints | Size | Job |
|---|---|---|---|
| **Micro** | Feature icons, list items, badges, tab icons, notifications | 16–48 px | Identify |
| **Spot** | Empty states, errors, success and confirmation, permissions, small promos | 96–240 px | Explain one idea, set tone |
| **Scene** | Onboarding, feature explainers, education, how-it-works | 320–800 px | Explain a sequence or relationship |
| **Hero** | Website heroes, campaigns, app-store art, OOH, social, press | 1000 px+ | Attract and express the brand |
| **Ambient** | Backgrounds, cards, packaging, slides, loading | any | Add brand texture without a message |
| **Motion** | Transitions, loaders, celebrations, micro-interactions | any | Show change and reward |

## 2. Mark the emotional temperature

For each touchpoint note whether the moment is **functional** (routine task), **sensitive** (money lost, fraud, error,
debt, health) or **celebratory** (goal reached, first payment, milestone). The same style rarely fits all three: the
character that celebrates a goal should not appear on a fraud alert. Record where illustration should be neutral or
absent. Do not overuse illustration when an icon or clear copy is enough.

## 3. Pick the proof touchpoints

Choose **two real moments** from the inventory that every direction must render, so the comparison is fair:

- one **spot** moment from product (e.g. "payment sent", "no transactions yet", "card frozen");
- one **scene or hero** moment (e.g. onboarding step 1, a feature launch, an app-store panel).

Prefer moments the brand actually has. If you have the product's UI, place the spot inside a phone frame or the real
component so the user sees it in context, not floating on a coloured square.

## 4. Write the touchpoint map into the spec

The final spec includes a table: touchpoint, tier, temperature, family, example asset. This is what lets another
designer pick the right kind of illustration for a new screen.

## Questions to ask if the inventory is unclear

- Where does the product currently use illustration, and where does it feel empty?
- Which moments matter most to the business (activation, first deposit, referral)?
- Who will make new illustrations after handover, and with which tools (Figma, Illustrator, Blender, Rive, Lottie)?
