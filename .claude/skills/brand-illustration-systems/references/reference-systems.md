# Reference-system lessons without visual borrowing

Use this as a menu of demonstrated system strategies, not a list of looks to imitate. When a user supplies a named
reference, analyse the actual work they supplied and extract only the qualities they identify as useful.

| System pattern | Family | Demonstrated approach | Transferable lesson |
|---|---|---|---|
| Type-derived in-product shapes | Brand device + flat | Curves, cuts and italic movement from the brand type become illustration geometry | Begin with existing identity assets before importing an outside source |
| Expressive global-use library | Line + character | Movement and personality replace generic flat figures; text and local symbols are restricted | Commission a distinctive hand and write global-use rules |
| Editorial in-product spots | Expressive line | Tone fences such as “warm but not cute” constrain hundreds of small scenes | Map tone and density to actual product surfaces |
| Spatial asset library | Soft 3D | Camera, materials, lighting and editable source scenes form the system | A 3D system needs a reproducible rig, not only renders |
| Explanatory 3D actions | Soft 3D | Dimensional objects clarify product states and actions | Depth can explain behaviour rather than decorate |
| Transforming narrative device | Brand device | One simple mark changes state to connect type, product and stories | A recurring device can add range without replacing existing warmth |
| Reduced-shape character world | Flat + character | Few vector shapes, strong silhouettes, exaggeration and controlled negative space | Shape-language rules let many artists remain consistent |
| Touchpoint-tiered library | Flat + technical + collage | Product spots, low-detail UI scenes, ambient patterns and campaign collage have separate jobs | Choose illustration type by touchpoint rather than forcing one mode everywhere |
| Category-notation system | Technical | Graphs, grids and modular layouts become the visual source | A category's own notation can become brand language |
| Small/hero format pairing | Expressive mixed media | Small icon-like assets and larger cropped heroes share one grammar | Plan format and crop rules, not only style |
| Security-print pattern system | Pattern-led + oblique depth | Guilloché-inspired faces, stacked-paper edges and diagrammatic construction share one source world | Pattern works when its source carries meaning and extends into structure and motion |

## How to use a supplied reference

1. Ask what the user admires: subject, composition, line, pattern, material, colour hierarchy, motion, or system range.
2. Separate documented facts from visual observations.
3. Record execution qualities as testable rules.
4. Rebuild when a close transfer is requested; use `reference-transfer.md`.
5. Derive the new metaphor, subjects, composition and identity from the current project.

Never use the table as permission to imitate a living artist, agency, mascot, or recognisable branded device.
