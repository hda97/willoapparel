Cara pakai setelah membeli

  1. Beli paket di lynk.id, lalu unduh file zip-nya.
  2. Ekstrak zip, buka file game (.html) dengan Chrome. Tidak perlu internet.
  3. Tampilkan di proyektor atau TV kelas, atau bagikan ke laptop dan tablet murid.
  4. Mau soal sendiri? Tekan tombol Guru, ganti soal atau tempel dari Excel, lalu unduh file game berisi soal Anda.

Pertanyaan guru

Apakah perlu internet?

Tidak. Setelah file diunduh, game jalan di Chrome tanpa internet.

Bisa dipakai di perangkat apa?

Laptop, komputer, tablet, dan HP Android atau iPhone yang punya browser Chrome atau Safari. Paling seru ditampilkan di proyektor atau TV kelas.

Apakah harus bisa coding untuk mengganti soal?

Tidak. Soal diganti lewat tabel di tombol Guru, bisa juga menempel langsung dari Excel. Video tutorial menunjukkan langkahnya.

Bagaimana cara membayar dan menerima file?

Pembelian lewat lynk.id. Setelah pembayaran selesai, file zip langsung bisa diunduh.

Kenapa ada tombol Contoh?

Tombol Contoh membuka versi contoh berisi 3 soal, untuk melihat tampilan game sebelum membeli. Versi lengkap untuk kelas, dengan semua soal, file tanpa internet, Mode Guru, dan video tutorial, ada di dalam paket.
