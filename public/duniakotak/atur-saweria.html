🧱 Atur Trakteer

Buka trakteer.id > menu Integrasi > Webhook. Isi Webhook URL dengan https://willoapparel.com/duniakotak/api/trakteer, salin Webhook Token-nya ke sini, lalu klik Simpan. Setelah itu traktiran Bata dengan kode DK masuk otomatis.

⭐ Atur Saweria (lama)

Halaman ini khusus admin Dunia Kotak. Tempel Stream Key dari link overlay Saweria, yaitu bagian setelah streamKey=. Key disimpan di server dan tidak akan ditampilkan lagi.
