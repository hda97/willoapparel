Dunia Kotak Pintar

Tiga game kuis untuk kelas. Satu bank soal (256 soal bawaan), pengaturan guru, dan bisa dimainkan tanpa internet.

🐱

Balap Kucing

Dua pemain adu cepat menjawab soal. Jawaban benar membuat kucingmu berlari ke garis finis.

🚩

Pawai Juara

Pimpin barisan pawai ke petak jawaban yang benar. Setiap jawaban benar menambah satu warga.

⛰️

Daki Puncak Pintar

Ular tangga gunung 64 petak untuk 2 sampai 4 siswa. Lempar dadu, jawab Tantangan Ilmu, capai puncak.

Untuk guru: buka game, ketuk Mode Guru di layar Pengaturan Soal untuk menempel soal dari Excel, lalu unduh file HTML berisi soal Anda.
