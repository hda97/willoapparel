Cara Menyiapkan Logo dan File Desain untuk Sablon Kaos

Logo terlihat bagus di layar HP, tapi saat dicetak di kaos hasilnya pecah, buram, atau warnanya berbeda. Masalah ini hampir selalu berasal dari file desain yang dikirim. Panduan ini menjelaskan file seperti apa yang sebaiknya disiapkan, dan apa yang bisa dilakukan kalau kamu hanya punya foto logo.

Saat memesan kaos untuk kelas, komunitas, atau usaha, hal pertama yang biasanya diminta admin adalah logo atau desain. Banyak orang lalu mengirim tangkapan layar dari Instagram, foto spanduk, atau gambar kecil dari grup WhatsApp. Di layar HP gambar itu terlihat baik-baik saja, tetapi setelah diperbesar seukuran dada kaos, garisnya bergerigi dan tulisannya kabur.

Kabar baiknya, kamu tidak perlu menjadi desainer untuk menyiapkan file yang baik. Cukup pahami beberapa hal dasar di bawah ini, lalu kirim apa yang kamu punya ke admin. Di bagian akhir ada cara memesan di Willo Apparel, Ngawi.

Kenapa logo bisa pecah saat dicetak

  • Gambarnya terlalu kecil. Gambar yang dikirim lewat chat sering diperkecil otomatis. Saat diperbesar untuk kaos, titik-titik gambarnya terlihat.
  • Hasil tangkapan layar. Tangkapan layar hanya menyimpan seukuran layar, sering lengkap dengan bayangan atau latar yang ikut tercetak.
  • Foto dari benda lain. Foto logo dari spanduk, stempel, atau kaos lama ikut membawa lipatan, pantulan cahaya, dan warna yang miring.
  • Latar belakang tidak transparan. Logo dengan kotak putih di belakangnya akan ikut tercetak kotak putih, terutama terlihat di kaos berwarna.

Mengenal jenis file desain

File vektor: paling ideal

File vektor seperti AI, EPS, SVG, CDR, atau PDF yang dibuat dari aplikasi desain menyimpan garis dan bentuk sebagai rumus, bukan titik. Karena itu file vektor bisa diperbesar sebesar apa pun tanpa pecah. Kalau logo organisasi atau usahamu dulu dibuat oleh desainer, tanyakan apakah mereka masih menyimpan file aslinya. File inilah yang paling dicari tim produksi.

File gambar beresolusi tinggi: masih bagus

Kalau tidak ada file vektor, file gambar seperti PNG atau JPG masih bisa dipakai asalkan ukurannya besar. Sebagai patokan sederhana, gambar yang sisi panjangnya sekitar 3000 piksel atau lebih biasanya cukup untuk desain di dada atau punggung. PNG dengan latar transparan lebih disukai karena tidak membawa kotak putih.

Gambar kecil atau foto: perlu dicek dulu

Gambar dari tangkapan layar, unduhan media sosial, atau foto benda belum tentu bisa langsung dicetak. Kirim saja ke admin, nanti admin memberi tahu apakah gambar itu cukup jelas atau perlu dirapikan lebih dulu.

Cara cepat mengecek file sendiri

  1. Buka gambar di HP atau laptop, lalu perbesar sampai sekitar seukuran telapak tangan atau lebih. Kalau tepi huruf mulai bergerigi atau kabur, gambar terlalu kecil.
  2. Lihat ukuran gambar di info file. Angka seperti 3000 x 3000 piksel jauh lebih aman daripada 500 x 500 piksel.
  3. Perhatikan latar belakang. Apakah ada kotak putih atau warna lain di belakang logo yang tidak ingin ikut tercetak?
  4. Periksa tulisan kecil. Slogan atau alamat yang terlalu kecil di logo bisa sulit terbaca setelah dicetak di kain.

Tips supaya hasil cetak sesuai harapan

  • Kirim file asli, bukan lewat galeri chat. Di WhatsApp, kirim gambar sebagai dokumen supaya ukurannya tidak diperkecil.
  • Sebutkan warna yang diinginkan. Warna di layar dan di kain bisa sedikit berbeda. Kalau punya kode warna atau contoh kaos dengan warna yang diinginkan, sertakan.
  • Pikirkan warna kaos. Logo gelap kurang terlihat di kaos hitam. Diskusikan versi logo terang untuk kaos gelap.
  • Jangan terlalu banyak detail kecil. Garis yang sangat tipis dan tulisan mungil kurang terbaca dari jarak beberapa langkah.
  • Pastikan kamu berhak memakai gambarnya. Pakai logo sendiri atau desain buatan sendiri, bukan karakter atau merek milik pihak lain.

Seperti apa prosesnya dari file sampai kaos

  1. Kirim logo atau desain lewat WhatsApp sebagai dokumen, beserta jumlah kaos dan warna yang diinginkan.
  2. Admin mengecek file dan memberi tahu apakah sudah cukup jelas untuk dicetak.
  3. Tim desain menyusun rancangan letak logo dan tulisan di kaos. Bantuan desain gratis dan bisa direvisi.
  4. Kamu menyetujui rancangan dan mengirim rekap ukuran.
  5. Kaos diproduksi dalam 3–7 hari kerja setelah desain disetujui, lalu diambil di workshop atau dikirim.

Ingin melihat dulu letak logomu di kaos? Unggah logomu di halaman desain kaos, atur posisinya, lalu kirim hasilnya ke admin sebagai bahan diskusi.
